## 安装

1. 手机浏览器打开本页，点击上面的下载链接
2. **下载完先在文件管理器里看一眼大小**（31 MB 或 45 MB）。差几百 KB 就是没下完，重新下
3. 从文件管理器点开安装
4. 若提示「禁止安装未知来源应用」，在设置里允许浏览器安装即可
5. 打开 App 会自动连接服务器，无需任何配置

> 遇到「解析软件包时出现问题」：基本是文件没下完整，或者是在微信 / QQ 里直接点开的（它们会改文件名）。用系统浏览器重新下，再从文件管理器安装。
