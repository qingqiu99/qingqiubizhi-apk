## 安装

1. 手机浏览器打开本页，点击上面的下载链接
2. 下载完成后点击安装
3. 若提示「禁止安装未知来源应用」，在设置里允许浏览器安装即可
4. 打开 App 会自动连接服务器，无需任何配置
